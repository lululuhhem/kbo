📥 선수 데이터 넣기

KBO 기록실(koreabaseball.com) 표를 복사해 붙여 넣으면, 2026 최종 기록으로 능력치·연봉·포지션을 계산해 새 players.js 파일을 만들어 줘요. PC에서 하는 게 편해요.

하는 방법

  1. KBO 홈페이지 → 기록실 → 선수기록 → 타자 / 투수 / 수비 선택
  2. 시즌 2026, 팀을 하나씩 고르면 그 팀 선수가 나와요. (페이지가 여러 개면 페이지마다)
  3. 표의 제목 줄(순위·선수명·팀명…)부터 마지막 줄까지 드래그해서 복사 → 아래 칸에 붙여 넣기. 여러 번 이어 붙여도 돼요.
  4. 타자는 기본기록1, 기본기록2(볼넷·삼진), 주루(도루) 표를 모두 붙이면 더 정확해요.
  5. 수비 표를 붙이면 그 선수가 2026년에 실제로 뛴 포지션이 정해져요. (수비 표가 없으면 기존 포지션 유지)
  6. 투수 역할은 자동 분류: 선발(SP) / 마무리(CP: 세이브 10개 이상 또는 팀 세이브 1위) / 중간(RP). 투수 표에 SV·HLD·GS 열이 있어야 정확해요.
  7. [계산하기] → 확인 → [players.js 내려받기] → GitHub 저장소의 players.js 와 바꿔 올리기
